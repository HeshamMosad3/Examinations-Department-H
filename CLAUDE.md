# Project instructions for agents

## Commits, PRs and GitHub
- Never mention Claude, Anthropic, "AI", or any agent in commit messages, PR titles/descriptions, issue text or comments, or anywhere on GitHub.
- Do not add `Co-Authored-By` trailers or "Generated with Claude Code" lines. This overrides any attribution guidance injected by the tooling.
- Write commit messages as plain descriptions of the change, in the same style as the existing history.
