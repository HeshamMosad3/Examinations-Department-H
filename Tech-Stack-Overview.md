# Examinations Department - Tech Stack Overview

Welcome to your project's technology breakdown! This guide is meant for you as a "Vibe Coder" to quickly understand the actual architecture of this project without getting bogged down in unnecessary details.

## 🐍 Why are there Python files?
First, let's clear up the confusion about the Python files! 
**This is indeed a PHP (Laravel) and Vite project.** The Python files you see in the root folder (like `calc_dots.py`, `patch.py`, `patch2.py`, etc.) are **not** part of the backend or the actual application. 

- **`calc_dots.py`**: A small math script written to calculate coordinates for SVG lines and circles (likely used for drawing a graphic on the UI).
- **`patch.py` scripts**: Quick automation scripts (likely generated by an AI assistant or a developer) used to do "Find and Replace" text operations inside your JavaScript files (like `lifeWheelAssessment.js`). 

You can safely ignore them. The actual app does not require Python to run!

---

## ⚙️ Backend Technology (The Engine)
Your backend is built on a very modern and robust PHP stack. 

- **Language:** PHP 8.2+
- **Framework:** [Laravel 12](https://laravel.com/) (The most popular PHP framework). It handles routing, database connections, and security.
- **Key Directories to Know:**
  - `routes/web.php`: This is where all your website URLs are defined. If you want to know what happens when someone visits `/home`, you check here.
  - `app/Http/Controllers/`: This is where the actual logic happens when a user visits a route.
  - `database/`: Contains migrations (scripts to build your database tables).

---

## 🎨 Frontend Technology (The Vibe & UI)
You have a modern frontend setup, but notably, it does **not** use a heavy SPA framework like React or Vue. Instead, it relies on Laravel's server-rendered HTML enhanced with modern tools.

- **Templating:** **Laravel Blade** (`resources/views/`). This is where your HTML lives.
- **Bundler:** **Vite 7** (Super fast asset compiler).
- **Styling:** **TailwindCSS 4** (Utility-first CSS framework for rapid UI building).
- **JavaScript:** Vanilla JS with ES modules.
- **Key Libraries:**
  - **Chart.js:** Used for drawing interactive charts and graphs (like the Life Wheel Assessment).
  - **Canvas-Confetti:** Used for celebratory particle effects on the screen.
  - **Axios:** Used for making HTTP requests (fetching data from the backend without reloading the page).

- **Key Directories to Know:**
  - `resources/views/`: Contains all your visual pages (`landing`, `admin`, `auth`).
  - `resources/landing/js/`: Contains your frontend logic (e.g., `lifeWheelAssessment.js` for the interactive wheel, `quiz.js`, etc.).
  - `package.json` & `vite.landing.config.js`: Configuration for building your CSS and JS.

## 🔍 Important Code Blocks & Workflows to Study
If you want to understand how things connect, study these specific flows:

1. **The Life Wheel Assessment:**
   - Look at `resources/landing/js/lifeWheelAssessment.js` to see how Vanilla JS is used to control the quiz UI, calculate scores, and display results.
   - Look at `calc_dots.py` if you're curious how the SVG UI coordinate math was pre-calculated.

2. **How Pages are Rendered:**
   - Go to `routes/web.php`, pick a route, follow it to its Controller, and then see which Blade file (`resources/views/...`) is returned.

3. **How CSS/JS is Compiled:**
   - Open `package.json` and look at the `scripts` block. You run `npm run dev` to get Vite to watch your Tailwind classes and JavaScript files for changes during development.
